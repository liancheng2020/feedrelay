# 开发计划

## 已实现

- YouTube、邮件和RSS定时采集，首次静默基线与持久去重。
- 视频字幕、本地音频转写、DeepSeek全文摘要及累计预算。
- 开启摘要的订阅先摘要后推送，微信/飞书单通道发送。
- AIHOT每日10点推送、订阅汇总、发送重试和人工核查。
- 更新列表、详情、分页、删除确认、配置导入导出及备份恢复。
- 本机免登录；可选单管理员密码访问。
- 跨平台用户托管命令、运行诊断、日志轮转和可选自动备份。
- 长摘要与采集/发送轮询分离，摘要单并发和租约保护不变。

## 下一步

1. 持续观察新内容采集到实际收件的成功率、耗时和错误分布。
2. 验证 Windows/Linux 真实系统托管和视频依赖，持续优化摘要队列等待。
3. 完善微信上下文过期后的恢复体验。
4. 验证Docker、目标服务器网络和升级恢复流程。

## 暂不开展

多人共享、组织权限、计费套餐和公共注册。开源使用者各自部署，数据与配置独立；多人共用需要单独建设用户、凭证、队列和预算隔离。
