# 验收、风险与参考

基线：2026-10-16。以下是未来的验证要求，不代表测试已经执行。当前只验证文档完整性。

## 1. 验证层次

1. 单元测试：标准化、身份键、匹配、时间、状态与错误分类。使用固定时间，不依赖真实网络。
2. 集成测试：临时数据库、IMAP/HTTP 模拟服务、实际事务和租约、崩溃与恢复。
3. 端到端测试：单用户管理页、鉴权、三类页面、后台任务与模拟推送。覆盖桌面和手机。
4. 真实小范围联调：经授权的一个公共频道、合成邮件与指定飞书目标，记录实际响应。
5. 连续试运行：7 个自然日的真实运行记录，不能以重复运行同一测试替代。

必要测试随里程碑开发，不把安全、只读或恢复验证全部推迟到试运行。外部服务不可达时，单元测试仍应可运行，但联调不得标为通过。

### 2.1 必要样例

- Atom：正常、乱序、重复 ID、标题变更、缺失字段、未来日期、超大与畸形内容。
- 邮件：纯文本、HTML、混合字符集、相同显示名、转发、旧 Date 新收件、多规则、超大附件、恶意链接与跟踪像素。
- IMAP：连续 UID、UID 跳号、UIDVALIDITY 变化、正文失败、连接中断和只读命令检查。
- 飞书：成功、HTTP 成功但业务拒绝、限流、配置失效、发送超时和接收后响应丢失。
- 恢复：事务回滚、磁盘满、租约过期、暂停竞态、发送后崩溃、过旧备份恢复。

样例必须合成或脱敏，避免真实名称、地址、邮件正文、令牌和 Webhook。自动化测试默认禁止真实网络，只有显式标注的联调命令可访问指定服务。

## 3. 真实联调与试运行记录

正式联调前落实 PRODUCT.md 的 Q-02 至 Q-06。连接测试也是外部操作，不因配置文件存在而自动获得任意邮箱读取或发送许可。

记录字段：版本/提交标识、时间与时区、来源匿名标识、授权范围、测试场景、发现数、待发送数、平台确认数、明确失败数、unknown 数、人工操作、耗时、覆盖缺口、结论与证据位置。

脱敏保留平台响应业务码与任务 ID，不能将完整 `.eml`、私人原文、App Secret 或 Webhook 放进报告。真实资料优先只保留本机受限位置；公开证据使用合成内容。

### 3.1 连续运行指标

| 指标 | 统计口径 |
| --- | --- |
| 检查成功率 | 成功检查任务 / 实际执行检查任务，区分无更新与失败 |
| 发现延迟 | 来源可确认提供/邮箱接收到条目至本机发现；来源时间不可靠时注明不可测 |
| 投递延迟 | 从本机发现到平台确认，展示积压与限额造成的等待 |
| 平台确认率 | sent / 已尝试投递；unknown 单列，不强归为成功或失败 |
| 重复情况 | 本地重复任务数量与实际观察到的重复消息分别记录 |
| 覆盖缺口 | 停机、Feed 窗口、UID 变化与无法人工核实的范围 |
| 人工介入 | 修改配置、重建基线、未知处置、显式重发的次数与原因 |

只在已人工对照的小范围内容上报告发现覆盖情况。没有可靠来源分母时，不公布“100% 不漏报”。累计测试数量不能代替稳定运行和用户实际阅读价值。

## 4. 风险与处置

| 风险 | 影响 | 首版处理 |
| --- | --- | --- |
| YouTube Feed 延迟或窗口不足 | 晚通知、停机期间可能漏发现 | 显示上次成功检查与不确定覆盖；不承诺实时，补查后置 |
| 频道格式或网络变化 | 无法读取 | 区分网络/解析错误、有限重试；不偷偷绕过登录或地域限制 |
| 邮件晚到、用户已经读过 | 按固定10点或未读过滤会漏报 | 周期扫描 UID，旧 Date 不阻止新到达条目 |
| IMAP 授权能力不足 | 接入失败或权限过大 | 专用邮箱优先，真实接入前核验范围；文件夹过滤不等于凭证最小权限 |
| 邮件发件人伪造 | 无关内容外发 | 不仅看显示名，保留邮箱反垃圾能力；无自动执行或可信身份承诺 |
| 邮件被发送到错误私聊目标 | 私人信息扩散 | 独立应用、固定用户 open_id、目标指纹；预览外发字段并确认，不提供公共私人原文 |
| Feed/HTML 恶意内容 | SSRF、XSS、跟踪、资源耗尽 | 受控网络、大小上限、安全解析与 HTML 清理，禁自动外链/图片 |
| 平台已收但响应丢失 | 重试可能重复 | unknown 单列，人工明确选择，状态可追查 |
| 正文与日志无限保留 | 隐私泄漏和磁盘增长 | 分层保留、清理快照、限量日志；保留最小身份而非无限保留内容 |
| 原始数据被自动提交 Git | 邮件或订阅关系公开 | 数据库、运行文件、Secret 和私人报告不进 Git；测试样例合成 |
| 引入模型自动总结 | 费用、数据外发与摘要失真 | v0.3 默认关闭，另行授权与总预算，失败降级 |
| 复制参考项目代码 | 许可证和维护负担 | 先借鉴行为，直接用协议库；复制代码前单独核验许可与声明 |

## 5. 发布与运维注意事项

- 不为方便部署关闭 TLS 校验、公开管理页或删除鉴权。
- 邮箱、飞书和后台登录使用不同凭证。Webhook 视为敏感令牌，不粘进截图、URL 参数或公开 issue。
- 本机运行依赖电脑在线，不能宣称关机后还能持续订阅；常驻部署需真实验证外网与邮箱端口可达。
- 本机 `127.0.0.1` 代理不能直接拿给远程容器使用；部署网络按实际环境配置。
- 优先本机/私有网络验证；外网演示独立运行合成数据，不直接展示真实订阅关系和邮件。
- 更新前备份并验证迁移；恢复数据库不意味着可以自动重发旧任务。
- 保留无模型模式；不得为了让演示“更智能”而默认增加付费转写或外部模型调用。
- 邮件和订阅内容的使用、公开展示、转发与模型处理分别考虑授权，不把个人可阅读理解成可以公开原文。

### 6.1 官方与库文档

- [YouTube 频道 Atom 与推送机制](https://developers.google.com/youtube/v3/guides/push_notifications)：新上传和标题/简介更新都可能产生事件，视频 ID 是重要身份字段。

- [ImapFlow](https://github.com/postalsys/imapflow)：连接和 UID 行为以所选版本文档及协议测试为准。
- [MailParser](https://nodemailer.com/extras/mailparser)：MIME 解析不是 HTML 安全清洗，需另外处理。
- [飞书应用发送消息](https://open.feishu.cn/document/server-docs/im-v1/message/create)、[应用 token](https://open.feishu.cn/document/server-docs/authentication-management/access-token/tenant_access_token_internal)：当前采用 token + open_id 单向私聊，真实应用配置尚未联调。
- [Vercel Cron 限制](https://vercel.com/docs/cron-jobs/usage-and-pricing)：截至查阅时，Hobby 单任务最低每日运行且非分钟级精确；实现前再确认。
