## 检查命令

```bash
npm run check
npx playwright install chromium
npm run test:e2e
```

check包含类型检查、单元/集成测试及生产构建。浏览器测试使用临时数据库和固定响应，不读取真实邮箱、不调用付费模型、不向真实接收端发消息。

## 常见问题

- **没有新内容**：检查服务和后台心跳、来源是否启用、采集间隔以及是否仍在建立首次基线。
- **已采集但未推送**：检查来源推送开关、摘要模式、来源授权、预算和通道是否就绪。按需模式需要手动生成。
- **视频处理慢**：查看当前阶段；本地完整转写可能需要数分钟，后续摘要仍按单并发排队，但其他来源采集和就绪消息发送继续轮询。已有有效缓存可复用。
- **YouTube失败**：检查服务端网络和两类代理配置；页面能播放不代表服务端能读取字幕。
- **微信发送失败**：确认绑定有效，向ClawBot发消息刷新上下文，再处理明确失败记录。
- **需人工核查**：先查看接收端是否已收到，再决定是否重发。不要只因页面未确认就反复点击。
- **无法本机访问**：核对AUTH_MODE、HOST和APP_ORIGIN，使用配置的地址和端口，不通过代理访问本机模式。

## 已知限制

电脑休眠和服务停止会暂停任务；仅熄屏但系统未休眠时可继续。上游Feed并非完整历史日志，长时间停机可能漏采。转写和模型可能误识别，定位片段不能证明结论正确。微信平台接受不等于已读，长期主动发送还受上下文有效期影响。Docker及公网部署须在目标环境验证。
